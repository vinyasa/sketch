# Project Rules & Customizations

## 📋 Session End / Tomorrow's TODO Tracking
- **Rule**: At the end of any day or session, if the user mentions working on something "tomorrow" or specifies next steps for tomorrow, the agent MUST automatically capture these tasks and add/update them under the **Tomorrow's Tasks** section in [todo.md](file:///d:/Antigravity Dev/BikerToddWeb/apps/sketch/docs/todo.md).
- Keep the `todo.md` list structured, organized, and clean. Remove tasks from "Tomorrow's Tasks" when they are completed or moved to the backlog.
