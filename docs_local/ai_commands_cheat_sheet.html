Little Lucey Woodcraft

AI Assistant Command Cheat Sheet

Select one or more components before giving a command, unless creating something new.

↔️ Making a Board Longer/Shorter

Automatically edits the longest dimension of the board.

  • Increase: grow, extend, increase, long, longer, length, add
    "Make this 2 inches longer"
  • Decrease: cut, trim, shave, chop, short, reduce, shrink
    "Trim 1/4 inch off the length"

↕️ Making a Board Wider/Narrower

Width is calculated as the middle-sized dimension.

  • Increase: wide, wider, width, increase, add
    "Make this 1 inch wider"
  • Decrease: narrow, reduce, decrease, shrink
    "Reduce the width by 3"

🗜️ Making a Board Thicker/Thinner

Calculated as the absolute smallest dimension.

  • Increase: thick, thicker, thickness
    "Make this 1/4 inch thicker"
  • Decrease: thin, thinner, shave, reduce
    "Shave 1/8 inch off the thickness"

📏 World Space Height

These commands specifically target the vertical World Y-Axis.

  • Increase: tall, taller
    "Make this 5 inches taller"
  • Decrease: short, shorter
    "Make it 2 inches shorter"

🧭 Moving & Nudging

Specify axis using names (X/Y/Z), colors (Red/Green/Blue), or directions (Up/Down/Left/Right/Forward/Back).

  • Commands: move, nudge
  • Positive: Up, Right, Forward
    "Move this 3 up"
  • Negative: Down, Left, Back
    "Nudge left 1/2 inch"

🔄 Rotating & Spinning

Change board orientation without destroying local dimensions.

  • Commands: rotate, spin, turn, orient
    "Rotate 90 on green"
  • Overrides: flip (180°), reset rotation (0,0,0)
    "Flip on Z"

🛠️ Tool Modifiers

Quickly apply CSG cuts via text.

  • Hole/Pocket: drill, bore, add
    "Drill a 2 inch hole along X"
  • Cove/Hollow: add, cut, make
    "Cut a 1/2 inch cove on bottom"
  • Arc/Cutout: add, cut, make
    "Cut curve 0 to 45 along z"

🧩 Generation & Macros

  • Material: walnut, pine, cherry, oak
    "Change to walnut"
  • Tapered Legs: taper, tapered leg
    "Add a tapered leg halfway"
  • Add Legs:
    "Add a leg" (Drops a standard 1.5x1.5 leg)
  • Auto-Tops: Computes bounding box of selection to generate a perfectly sized top.
    "Put a top on this"
  • Box/Cabinet Builder:
    "Build a 24 inch tall box"
